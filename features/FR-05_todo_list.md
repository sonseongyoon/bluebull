# FR-05: 제미나이 가이드 기반 일일 투두 리스트(To-Do List)

## 1. 기능 개요
사용자는 제미나이 AI가 당일 신체 프로필과 설정 목표에 최적화하여 작성해 준 일일 운동 및 식단 실천 리스트를 직접 전달받아 수행 여부를 실시간 체크하고 동기부여 격려 팝업 칭찬 가이드를 노출합니다.

## 2. 세부 구현 사항

### A. 제미나이 추천 투두 생성 및 파싱
*   **컴포넌트**: `GeminiClient.kt` 내 `generateTodoList` 함수
*   **API 구현**:
    *   제미나이 AI에게 "체중 상태 및 다이어트/벌크업 방향성을 토대로 오늘 완수해야 할 운동 루틴 2가지와 식단 조절 3가지를 JSON Array 형식으로 회신해달라"는 특수 구조 프롬프트를 구성해 발신합니다.
    *   반환된 JSON을 정밀 파싱하여 `TodoItem` 개체 리스트로 전환합니다.
    *   통신 장애 시 벌크업/다이어트 목적에 특화된 5개 커스텀 식단/운동 고정 루틴이 대체 작동합니다.

### B. 투두 리스트 관리
*   **컴포넌트**: `GoalTodoScreen.kt` 내 추천 및 관리 영역
*   **주요 기능**:
    *   '추천받기' 버튼이나 헤더의 새로고침을 누르면 이전 AI 투두를 지우고 오늘 날짜 전용 추천 리스트를 동적으로 교체합니다.
    *   사용자는 직접 원하는 항목을 체크박스로 클릭하여 완료 처리(`isCompleted`)할 수 있으며, 휴지통 아이콘으로 삭제하거나 '할 일 추가' 대화창을 띄워 커스텀 운동/식단 항목을 개별 등록할 수 있습니다.

### C. 완수 칭찬 축하 팝업 연동
*   **컴포넌트**: `GoalTodoScreen.kt` 내 축하 연출
*   **동작 흐름**:
    *   오늘 기재된 모든 실천 루틴 항목을 완료 상태로 체크하여 달성률이 100%가 되는 순간, AI가 회원님의 오늘의 행동을 진심으로 응원하는 칭찬 메시지와 함께 특별 제작된 네온 퍼플 테마의 **'오늘의 루틴 완벽 달성!' 축하 다이얼로그창**이 팝업으로 노출되어 성취감을 제공합니다.
