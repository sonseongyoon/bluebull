# FR-01: 실시간 인바디 데이터 등록 및 변화 추이 시각화

## 1. 기능 개요
사용자는 본인의 체성분 상태를 지속적으로 기록하고 관리할 수 있으며, 시스템은 입력된 데이터를 시간 흐름에 따른 꺾은선형 라인 그래프와 상세 수치 카드로 시각화하여 제공합니다.

## 2. 세부 구현 사항

### A. 인바디 데이터 입력 및 등록
*   **컴포넌트**: `MeasurementScreen.kt`
*   **입력 항목**: 체중(kg), 골격근량(kg), 체지방률(%), 체수분량(%)
*   **검증 및 저장**:
    *   사용자가 숫자가 아닌 문자를 입력하거나 범위를 벗어날 경우 입력 제한.
    *   저장 완료 시 `PreferencesManager.addInbodyRecord`를 통해 SharedPreferences에 JSON 데이터 형태로 기록을 안전하게 누적합다.
    *   입력이 끝나면 `onSave()` 콜백을 호출하여 홈 화면으로 자동으로 라우팅시킵니다.

### B. 핵심 지표 그리드 시각화
*   **컴포넌트**: `DashboardScreen.kt`
*   **표시 항목**: 체중, 체지방률, 골격근량, BMI, 체수분량, 기초대사량(BMR) 등 6대 핵심 수치를 카드 그리드로 배치했습니다.
*   **변화량 추적**: 이전 기록(최근 2번째 기록)이 존재할 경우, 각 카드 우측 상단에 최근 측정치 대비 변화량(예: `↗ 0.8` 또는 `↘ 1.2`)을 빨간색/초록색 화살표 배지와 함께 표시하여 한눈에 체성분 변화를 직관적으로 비교할 수 있습니다.

### C. 추이 선 그래프 시각화
*   **컴포넌트**: `AnalysisScreen.kt` 및 `CustomLineChart.kt`
*   **기능**:
    *   축적된 인바디 데이터를 바탕으로 추이를 직관적으로 확인할 수 있는 커스텀 선 그래프를 그립니다.
    *   선택한 세부 탭(체중, 체지방률, 근육량, 체수분)에 맞춰 상단 탭 하이라이트 효과가 실시간 반영됩니다.
    *   기록의 전체 데이터를 분석하여 최고치, 최저치, 그리고 평균 수치를 계산해 주는 상세 요약 카드가 제공됩니다.
