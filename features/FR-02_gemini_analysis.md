# FR-02: 제미나이 AI 맞춤형 종합 분석

## 1. 기능 개요
사용자가 측정하고 누적한 인바디 기록을 활용하여, 인바디 상태 분석 및 헬스 가이드가 담긴 커스텀 피드백 리포트를 제미나이 AI가 자동으로 생성해 제공합니다.

## 2. 세부 구현 사항

### A. 분석 리포트 프롬프트 빌드
*   **컴포넌트**: `GeminiClient.kt` 내 `generateAnalysisReport` 함수
*   **구현 로직**:
    *   사용자의 프로필 정보(성별, 나이, 키)와 측정 이력의 첫 번째(First) 및 최신(Latest) 레코드를 결합합니다.
    *   체중 변화, 골격근량 변화, 체지방률 변화량을 소수점 첫째 자리까지 정밀 계산하여 프롬프트 컨텍스트에 삽입합니다.
    *   전문적인 스포츠 의학 및 영양학 피트니스 가이드 톤앤매너로 답변을 받기 위한 지침을 작성합니다.

### B. 개인정보 보호 마스킹 (PII Masking)
*   **컴포넌트**: `GeminiClient.kt` 내 `maskPII` 함수
*   **구현 로직**: 외부 제미나이 서버로 전달되는 사용자의 정보 보호를 위해 실명(userName)은 `"사용자(Masked)"`로 치환하고, 이메일이나 전화번호와 같은 민감한 데이터 패턴이 존재할 경우 정규식을 이용하여 자동으로 마스킹 처리를 진행한 후 안전하게 API를 호출합니다.

### C. 로컬 지능형 시뮬레이터 구성 (Fallback Simulator)
*   **컴포넌트**: `GeminiClient.kt` 내 `simulateAnalysisReport` 함수
*   **구현 로직**:
    *   Gemini API Key가 누락되었거나 통신 지연 혹은 네트워크가 단절된 비정상적인 오프라인 상황에서도 리포트 생성이 끊기지 않도록 고성능의 시뮬레이터를 구현했습니다.
    *   실제 골격근의 증가율과 체지방 감소 상태 등을 감지하여 '린매스업(Lean Mass Up)', '벌크업 성공', '유산소 과다 근손실', '정체기 과도기' 등 4가지 시나리오의 전문 맞춤 텍스트 및 일일 단백질 추천 섭취량을 동적으로 계산하여 피드백을 실시간으로 반환합니다.
